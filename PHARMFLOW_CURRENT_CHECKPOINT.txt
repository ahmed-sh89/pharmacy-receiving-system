## FULL TRACE FINDING
The repeated persistence/sign-in fixes were not all reaching the browser runtime.

The deployed index.html still referenced stale cache keys:
- auth.js -> 2C1070
- session.js -> 2C1146
- cloud-workspace.js -> 2C1147

while newer fixes had already been written into those files.

This meant Chrome could continue executing older cached JavaScript even after the
new source files were uploaded to GitHub. It also explains why later fixes appeared
to have no effect despite correct source changes.

## ROOT FIX
This release consolidates the latest intended versions of all startup/persistence
files and gives them ONE new runtime version key: 2C11411.

Included:
- state.js: server-authoritative first state
- app.js: await cloud hydration before first UI
- auth.js: keep auth gate until hydration completes
- session.js: complete finalize cleanup
- cloud-workspace.js: persist/clear full cloud workspace after finalize
- index.html: exact cache-busting refs for all five files

# PHARMFLOW CURRENT CHECKPOINT

Date: 23 August 2026
Version: Phase 2C.11.4.10 — Finalize Persistence Root Fix
Status: READY FOR TEST

## DIAGNOSTIC RESULT
After two Orders were independently finalized and archived:
- Active Order Manifest was cleaned correctly.
- Receiving eventually became empty.
- Sign Out -> Sign In still flashed stale 328 items / 956 scans.
- Reset Current Workspace made the flash disappear permanently.

This diagnostic proves the stale data was persisted CURRENT WORKSPACE state,
not Historical Archive and not merely a rendering/auth-gate problem.

## FULL TRACE ROOT CAUSE
PharmFlow has TWO synchronized current-workspace authorities:
1. pharmflow_active_order_manifest_v1 — structural active Orders.
2. the legacy/full Cloud Workspace snapshot — workspace/session compatibility.

2C.11.4.6 updated/cleared #1 after Finalize but did not overwrite #2.
The full Cloud Workspace therefore still contained finalized Orders,
receivingHistory and old session scan state.

On later hydration, that stale snapshot could be restored before the empty
Active Manifest reconciled it. Reset Current Workspace appeared to fix the
problem because its server RPC clears BOTH authorities.

## ROOT FIX
Finalize now completes one end-to-end persistence transaction in application flow:

Selected Order Finalize:
- archive selected Order only;
- remove only its source quantities and receiving transactions;
- if other active Orders remain:
  - rebuild/recalculate the reduced workspace;
  - reset current-workspace scan total to the remaining transaction ledger;
  - save the reduced Active Order Manifest;
  - overwrite the full Cloud Workspace with the SAME reduced state;
- if the last active Order is finalized:
  - reset the Current Workspace and operational session to true empty state;
  - clear the Active Order Manifest;
  - overwrite the full Cloud Workspace with an explicit EMPTY snapshot;
- only after both server authorities accept the new state is local persistence saved and success UI shown.

## DATA BOUNDARIES PRESERVED
- Receiving Archive: untouched except normal selected-order archive creation.
- Global GTIN: untouched.
- Returns Archive: untouched.
- Near Expiry: untouched.
- Historical Data: untouched.
- Authentication/account isolation: unchanged.
- No SQL migration.
